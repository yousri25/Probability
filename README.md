# 📘 Probability Revision Site

A simple revision website for the Probability course (2026-27): combinatorics, events, conditional probability and random variables, with diagrams and solved exercises. Content is in French.

## Usage

Open `index.html` in a browser, or enable **GitHub Pages** (Settings → Pages → `main` branch).

## Note

Solutions are not official corrections. Check them against your teacher's answers.
