1Analyse combinatoire

Objectif : compter les éléments d'un ensemble fini. Notation : card(Ω) = nombre d'éléments de Ω.

Outil : quelle formule ?

L'ordre compte-t-il ?

Répétition autorisée ?

Répondez aux deux questions…
Permutation
Tous les n éléments sont utilisés.
Pₙ = n!
Avec répétition (classes n₁…nk) :
n! / (n₁! n₂! … nk!)
Arrangement
p parmi n, ordre important.
Anp = n! / (n−p)!
Avec répétition :
np
Combinaison
p parmi n, ordre sans importance.
Cnp = n! / (p!(n−p)!) = Anp/p!
Avec répétition :
Cn+p−1p

2Événements & probabilités

Vocabulaire

  • Univers Ω : tous les résultats possibles
  • Événement : A ⊂ Ω
  • Contraire Ā : ce qui n'est pas dans A
  • Incompatibles : A ∩ B = ∅
  • Ω = certain, ∅ = impossible
  • Système complet : Aᵢ deux à deux incompatibles et ∪Aᵢ = Ω

Propriétés d'une probabilité P

P(Ω)=1 · P(∅)=0 · 0 ≤ P(A) ≤ 1 · P(Ā)=1−P(A)
P(A∪B) = P(A)+P(B)−P(A∩B)
P(A∪B∪C) = ΣP − Σ P(deux à deux) + P(A∩B∩C)
A⊆B ⇒ P(A) ≤ P(B) et P(B∖A)=P(B)−P(A)
Équiprobabilité : P(A) = card(A) / card(Ω)

Indépendance

A, B indépendants ⇔ P(A∩B) = P(A)·P(B)
Alors (A, B̄), (Ā, B), (Ā, B̄) le sont aussi. Pour n événements : la formule doit marcher pour tout sous-ensemble d'indices.
Piège
« Deux à deux indépendants » ≠ « mutuellement indépendants ».

P(A∩B)=P(A∩C)=P(B∩C)=1/4 = 1/2·1/2 ✔ (2 à 2).
Mais A∩B ⊂ C donc P(A∩B∩C)=1/4 ≠ 1/8 = P(A)P(B)P(C) ✘.

3Probabilité conditionnelle

P(A | B) = P(A∩B) / P(B)  (P(B) > 0)
P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)
Si A, B indépendants : P(A|B)=P(A).
Probabilités totales
P(B) = Σₙ P(B|Aₙ)·P(Aₙ)
(Aₙ) système complet.
Bayes
P(Aₖ|B) = P(B|Aₖ)P(Aₖ) / Σₙ P(B|Aₙ)P(Aₙ)
Probabilité « inversée ».

B est découpé en morceaux B∩Aᵢ : on les additionne.

P(R∩B)=0,9×0,8=0,72 · P(R̄∩B)=0,1×0,3=0,03
P(B)=0,72+0,03=0,75 (probabilités totales)
P(R|B)=0,72/0,75=0,96 (Bayes)

4Variables aléatoires

v.a.r. X : Ω → ℝ associe un réel à chaque issue. X(Ω) = valeurs prises. Discrète : X(Ω) fini ou dénombrable. Continue : X(Ω) = intervalle(s).

Discrète

Loi : P(X=xᵢ), Σ P(X=xᵢ)=1
F(x)=P(X≤x)=Σxᵢ≤xP(X=xᵢ)
E(X)=Σ xᵢ P(X=xᵢ)

Continue

Densité f ≥ 0, ∫f = 1
F(x)=∫−∞x f(t)dt
E(X)=∫ x f(x)dx
P(X=a)=0

Propriétés de F

  • croissante ; limites 0 en −∞ et 1 en +∞
  • continue à droite (discret) / continue partout (continu)
  • P(a<X≤b)=F(b)−F(a) · P(X>a)=1−F(a)
  • discret : P(X=xᵢ)=F(xᵢ)−F(xᵢ₋₁)
Espérance
E(X+Y)=E(X)+E(Y) · E(αX)=αE(X) · E(α)=α · E(φ(X))=Σφ(xᵢ)P(X=xᵢ)
Variance
V(X)=E(X²)−(E(X))²
V(α)=0 · V(αX)=α²V(X) · V(X+α)=V(X)
